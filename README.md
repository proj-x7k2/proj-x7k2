# 수의영상의학 논문 위키 — 시작 가이드

이 프로그램은 매주 PubMed에서 수의영상의학 관련 새 논문을 찾아서,
Claude가 영문/국문으로 요약해주고, 그 결과를 Obsidian 위키 노트와
검색 가능한 웹사이트 양쪽에 자동으로 쌓아줍니다.

코딩을 몰라도 따라 할 수 있도록 순서대로 설명합니다. 중간에 막히면
그 단계에서 멈추고 무엇이 안 되는지 알려주시면 도와드릴게요.

---

## 0. 전체 흐름 미리 보기

```
PubMed 검색 → 새 논문 발견 → Claude가 요약 → Obsidian 노트 + 웹사이트 데이터 저장
```

> **두 가지 실행 방법이 있습니다.**
> - **(A) 완전 자동, 추가 비용 없음 (추천)**: Claude Code + 구독 계정을 씁니다. 4~6단계(API 키 발급)를 건너뛰고 바로 9단계로 가세요.
> - **(B) 수동 실행, API 별도 과금**: `summarize.py`가 Anthropic API를 직접 호출합니다. 1~8단계를 따라가면 됩니다.
> 아래 폴더 구성에 두 방법에 쓰이는 파일이 모두 나와 있습니다.

폴더 구성:
- `fetch_papers.py` : PubMed에서 새 논문을 찾는 코드 (두 방법 공통, 비용 없음)
- `summarize.py` : (B) Claude API로 요약을 만드는 코드 — API 키 필요, 별도 과금
- `main.py` : (B) 위 두 개를 순서대로 실행해주는 코드
- `run_weekly.sh` : (A) 검색+요약을 한 번에 자동 실행하는 스크립트 — 구독 사용량으로 처리, 9단계에서 설정
- `summarize_prompt.txt` : (A) Claude Code에게 전달하는 요약 지시문 (문구만 수정 가능)
- `config.py` : 검색 키워드·저널을 수정하는 곳
- `obsidian_notes/` : 요약 결과가 마크다운 노트로 쌓이는 폴더
- `website/index.html` : 논문 목록을 볼 수 있는 웹페이지
- `data/papers.json` : 웹사이트가 읽어가는 데이터 (직접 안 만져도 됩니다)

## 1. 컴퓨터에 Python 설치하기

Python은 이 코드를 실행하기 위한 프로그램 언어입니다.

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.x.x" 버튼 클릭해서 설치 파일 받기
3. 설치 시작할 때 **"Add Python to PATH"** 체크박스를 꼭 체크하세요 (윈도우 기준)
4. 설치가 끝나면, 터미널(윈도우는 "명령 프롬프트" 또는 "PowerShell", 맥은 "터미널" 앱)을 열고 아래를 입력해보세요:

   ```
   python --version
   ```

   `Python 3.x.x` 같은 글자가 나오면 성공입니다.

## 4. Claude API 키 발급받기

이 키는 Claude에게 "이 논문 요약해줘"라고 요청할 때 필요한 인증 정보입니다.
(claude.ai 로그인과는 별개의, 개발자용 키입니다.)

1. https://console.anthropic.com 접속 후 로그인/가입
2. 왼쪽 메뉴에서 **API Keys** 클릭
3. **Create Key** 버튼으로 새 키 생성 → 화면에 뜬 키 문자열을 복사 (한 번만 보여지니 꼭 복사해두세요)
4. 참고: API 사용은 유료입니다 (충전식 크레딧). 논문 초록 요약 정도는 편당 비용이 매우 작지만, console.anthropic.com의 Billing 메뉴에서 소액 충전이 필요할 수 있습니다.

## 7. 실행하기

터미널에서:

```

```

그러면 이렇게 진행됩니다:
1. "1단계: 새 논문 검색" — PubMed에서 최근 논문을 찾습니다

- `obsidian_notes/` 폴더에 논문별 마크다운 노트가 생깁니다 → 이 폴더를 통째로 기존 Obsidian 볼트 안에 복사하거나, 아예 이 폴더를 Obsidian에서 볼트로 열면 됩니다.
- `data/papers.json` 에 웹사이트용 데이터가 쌓입니다.

## 9. 완전 자동화 설정하기 (매주 손 안 대고 실행)

이 프로젝트는 두 단계로 이루어져 있습니다:
- **논문 검색**: PubMed에 요청만 하는 것이라 원래부터 비용이 전혀 없습니다.
- **요약 생성**: Claude Code를 씁니다. 유료 구독(Pro/Max 등)에 이미 포함된 사용량으로 처리되도록 설정할 겁니다.

이제 이 두 단계를 하나로 묶어 자동 실행하는 `run_weekly.sh`를 이미 만들어뒀습니다.
아래 순서대로 **한 번만** 설정하면 그 다음부터는 완전히 자동으로 돌아갑니다.

### 9-1. Claude Code 설치 확인

터미널에 아래를 입력해서 이미 설치되어 있는지 확인하세요:
```
claude --version
```
버전 번호가 나오면 설치되어 있는 것입니다. 만약 "command not found"가 뜨면:
```
npm install -g @anthropic-ai/claude-code
```
로 설치하세요 (Node.js가 먼저 설치되어 있어야 합니다. https://nodejs.org 에서 받으세요).

### 9-2. 구독 계정 인증 토큰 만들기 (매우 중요한 단계)

이 토큰이 있어야 자동 실행될 때 "내 Pro/Max 구독 사용량"으로 처리됩니다.
이 단계를 건너뛰면 자동화가 아예 동작하지 않거나, 최악의 경우 별도 API 과금으로 샐 수 있으니 꼭 진행하세요.

```
claude setup-token
```
을 입력하면 브라우저가 열리고, 평소 claude.ai에 로그인하는 구독 계정으로 로그인 및 승인하라고 나옵니다.
승인하면 터미널에 긴 문자열(토큰)이 출력됩니다.

이 문자열을 복사해서, 프로젝트 폴더 안에 `claude_token.txt` 라는 새 파일을 만들고 그 안에 붙여넣은 뒤 저장하세요.
(이 파일도 `.env`처럼 절대 다른 사람과 공유하거나 인터넷에 올리지 마세요.)

### 9-3. 안전장치 — 지출 한도를 0원으로 걸어두기 (권장)

혹시 모를 상황에 대비해, console.anthropic.com → **Settings → Billing → Spend limits** 에서
월 지출 한도를 **$0**으로 설정해두세요. 이렇게 해두면 만에 하나 자동화가 구독이 아닌 API 쪽으로
잘못 요청을 보내는 경우에도, 돈이 빠져나가는 대신 요청이 그냥 차단됩니다.

### 9-4. 자동 실행 스케줄 등록하기 (Mac 기준)

1. 터미널에서:
   ```
   crontab -e
   ```
2. 처음 열면 편집기가 뜹니다 (vi 또는 nano). 맨 아래에 이 줄을 추가하세요
   (경로는 실제 프로젝트 폴더 경로로 바꾸세요):
   ```
   0 9 * * 1 /bin/bash /Users/kka/Desktop/vet_paper_wiki/run_weekly.sh
   ```
   이 줄은 "매주 월요일 오전 9시에 run_weekly.sh 실행"이라는 뜻입니다.
   (`0 9 * * 1` 부분을 바꾸면 요일/시간을 조정할 수 있습니다.)
3. 저장하고 닫으면 (nano 기준: Ctrl+O → Enter → Ctrl+X) 등록 완료입니다.

Windows를 쓰신다면 "작업 스케줄러(Task Scheduler)"에서 같은 방식으로
`run_weekly.sh` 대신 동일한 명령을 담은 `.bat` 파일을 매주 실행하도록 등록하면 됩니다.
필요하시면 Windows용 파일도 만들어드릴 수 있어요.

### 9-5. 잘 도는지 확인하는 방법

- 실행될 때마다 `logs/` 폴더에 그날 날짜의 로그 파일이 생깁니다. 열어보면 몇 편을 찾았고
  어떻게 처리했는지 그대로 남아있습니다.
- 처음에는 자동 스케줄을 기다리지 말고, 터미널에서 직접 한 번 실행해서 잘 되는지 확인해보세요:
  ```
  ./run_weekly.sh
  ```
- Claude Code 사용량이 궁금하면 claude.ai의 **Settings → Usage** 에서 확인할 수 있습니다
  (여기서 API 과금이 아니라 구독 사용량으로 잡히는지 확인하시면 안심이 됩니다).

## 9-6. (업그레이드) 그냥 쌓이는 노트가 아니라 진짜 "위키"로 만들기

지금까지 방식은 논문마다 독립된 요약 카드를 쌓는 것에 가까웠습니다. 여기서 한 단계
더 나아가서, **주제별로 지식이 누적되는 진짜 위키**로 업그레이드했습니다.

핵심은 프로젝트 폴더에 있는 **`CLAUDE.md`** 파일입니다. Claude Code는 실행될 때마다
이 파일을 자동으로 읽어서 "위키를 어떻게 관리해야 하는지" 규칙으로 삼습니다. 그래서
`summarize_prompt.txt`는 아주 짧아졌고, 실제 상세 규칙은 전부 `CLAUDE.md`에 있습니다.

**바뀐 폴더 구조:**
```
obsidian_notes/
  papers/{연도}-{제목}.md   ← 논문 한 편당 페이지 (기존과 비슷)
  topics/{주제}.md          ← 새로 생김: 여러 논문이 누적되는 주제별 종합 페이지
  overview.md               ← 새로 생김: 위키 전체를 조망하는 개관
```

새 논문이 들어올 때마다 Claude Code는:
1. 논문 페이지를 만들고
2. 관련된 주제 페이지가 이미 있으면 **읽어본 뒤 통합**해서 갱신하고 (덮어쓰지 않음)
3. 기존 결론과 다른 내용이 나오면 "상충되는 근거" 섹션에 명시적으로 남기고
4. 전체 개관(`overview.md`)도 갱신합니다.

**이미 만들어진 7편의 노트가 있다면**, 새 구조에 맞게 한 번만 옮겨주세요:
```
mkdir -p obsidian_notes/papers
mv obsidian_notes/*.md obsidian_notes/papers/ 2>/dev/null
```
(이미 `overview.md`가 있다면 이 명령어가 그것까지 옮기려 할 수 있으니, 옮긴 후
`obsidian_notes/papers/overview.md`가 있으면 `obsidian_notes/`로 다시 옮겨주세요.)

이후 `./run_weekly.sh`를 실행하면 그때부터 `topics/`와 `overview.md`가 자동으로
채워지기 시작합니다.



기존에 쓰시던 위키는 삭제하셨으니, 이 프로젝트의 `obsidian_notes` 폴더를 **그 자체로 새 볼트(Vault)** 로 쓰는 게 가장 간단합니다. 매주 자동 실행될 때마다 이 폴더 안에 노트가 계속 쌓이고, Obsidian은 그 폴더를 실시간으로 보여줄 뿐이라서 별도로 옮기거나 합칠 필요가 없습니다.

1. Obsidian 앱 실행
2. 왼쪽 아래 볼트 아이콘 클릭 → **"Open folder as vault"** (또는 시작 화면의 "폴더를 볼트로 열기")
3. `vet_paper_wiki/obsidian_notes` 폴더 선택

이제부터 자동화가 돌 때마다 새 논문 노트가 이 볼트에 자동으로 추가됩니다. Obsidian을 열어둔 상태라면 파일이 추가되는 즉시 왼쪽 목록에 나타납니다.

**태그/그래프 활용 팁**: 각 논문 노트에는 `#MRI`, `#oncology` 같은 태그와 함께, 관련 주제 페이지로 가는 링크(`[[topics/...]]`)가 자동으로 붙습니다. Obsidian 왼쪽의 "태그" 패널이나 그래프 뷰(오른쪽 위 그래프 아이콘)를 열면, 논문 → 주제 → 다른 논문으로 이어지는 연결이 그대로 보여서 진짜 "위키"다운 탐색이 가능합니다. `overview.md`를 열면 전체 그림도 한눈에 볼 수 있어요.

## 11. 웹사이트를 다른 사람과 공유하기 (GitHub Pages)

지금까지 만든 `website/index.html`은 경아님 컴퓨터에서만 보입니다. **다른 사람도 볼 수 있는 진짜 인터넷 주소**로 만들려면 GitHub Pages를 씁니다 (무료).

### 11-1. Git 설치 확인
```
git --version
```
버전이 안 뜨면 https://git-scm.com/download/mac 에서 설치하세요.

### 11-2. GitHub 계정 만들기
https://github.com 에서 무료 계정을 만드세요 (이미 있으면 건너뛰세요).

### 11-3. 새 저장소(repository) 만들기
1. GitHub 로그인 후 오른쪽 위 **+** → **New repository**
2. 이름을 정하세요 (예: `vet-paper-wiki`)
3. **Public**으로 설정 (Pages를 무료로 쓰려면 공개 저장소여야 합니다 — 논문 요약 내용이라 공개해도 괜찮은 정보입니다)
4. **Create repository** 클릭 (다른 옵션은 건드리지 마세요)

### 11-4. 내 컴퓨터의 프로젝트를 GitHub에 올리기

터미널에서 **프로젝트 폴더 안**으로 이동한 상태에서, 아래를 순서대로 한 줄씩 입력하세요
(`사용자이름`과 `저장소이름`은 방금 만든 걸로 바꾸세요):

```
git init
git add .
git commit -m "첫 업로드"
git branch -M main
git remote add origin https://github.com/사용자이름/저장소이름.git
git push -u origin main
```

처음 push할 때 GitHub 로그인 창이 뜰 수 있습니다. 브라우저로 로그인해서 승인하세요.

> `.gitignore` 파일을 이미 만들어뒀기 때문에, `claude_token.txt`나 `.env` 같은 민감한 파일은 자동으로 제외되고 올라가지 않습니다. 안심하고 진행하셔도 됩니다.

### 11-5. GitHub Pages 켜기

1. GitHub에서 방금 만든 저장소 페이지로 이동
2. 상단 **Settings** 탭 클릭
3. 왼쪽 메뉴에서 **Pages** 클릭
4. "Branch" 부분에서 `main` 선택, 폴더는 `/ (root)` 선택 → **Save**
5. 1~2분 기다리면 화면에 `https://사용자이름.github.io/저장소이름/` 같은 주소가 나타납니다

### 11-6. 실제 웹사이트 주소

논문 목록 페이지는 아래 주소가 됩니다 (뒤에 `website/`를 꼭 붙이세요):
```
https://사용자이름.github.io/저장소이름/website/
```

이 주소는 **누구에게나 공유 가능**합니다.

### 11-7. 이후엔 자동으로 갱신됨

1. 새 논문 검색
2. Claude Code로 요약
3. **결과를 GitHub에 자동으로 올려서, 공유된 웹사이트도 같이 갱신**
