# 교정 요청

위키 내용 중 틀리거나 과장되거나 어색한 부분을 아래 **요청**에 적어두면, Claude가 고칩니다.
맥북에서 저장하면 15분 안에 GitHub에 올라가고, 바로 반영돼요.

- 한 줄에 하나씩 `- [ ]`로 시작해서 적어주세요.
- 어느 페이지인지(논문 PMID나 제목 일부, 주제 이름)와 무엇이 문제인지 적으면 됩니다.
- 반영되면 아래 **반영 완료**로 옮겨지고 `- [x]`로 바뀌며, 무엇을 고쳤는지 덧붙여집니다.
- 앞으로도 지켜야 할 원칙이면 Claude가 규칙으로 기억해서 같은 실수를 반복하지 않습니다.

적는 예시:
```
- [ ] 42722611 MMVD 논문: 임상 시사점의 "확진 가능"은 과장. 초록상 보조 지표일 뿐임.
- [ ] 전체: VHS는 풀어 쓰지 말고 약어 그대로 써줘.
```
